# Calculator

This project is a aesthetic calculator built using HTML, CSS, and JavaScript.

All the HTML, CSS, and JavaScript are combined into one file for simplicity and organization, making it easy to manage and run without multiple files.

The calculator includes basic arithmetic operations, along with additional features like keyboard input, memory functions, scientific mode, and a theme switcher.

## How to Run
Just open the .html file in your browser, using live server.

## Technologies Used
- HTML
- CSS
- JavaScript
